### Featured Systems & Engineering Case Studies

#### 1. PharmaTrace // Enterprise Pharmaceutical Traceability Platform
*DSCSA Title II & GxP compliant anti-counterfeiting network combining Event Sourcing with EVM cryptographic anchoring.*

- **High-Throughput Saga Engine:** Off-chain distributed state machine handling **2,378,398 ops/sec** (0.32 $\mu$s mean latency) with automated quarantine and recall circuit breakers.
- **On-Chain Cryptographic Anchoring:** Batch attestation aggregating off-chain events into Merkle trees committed to EVM contracts at **43,500+ events/sec**.
- **Collateral Bonding & Slashing:** Smart contract escrow requiring logistics carriers to bond collateral, programmatically slashed via Chainlink Automation upon thermal excursion breaches ($2^\circ\text{C}$ to $8^\circ\text{C}$).
- **Zero-Knowledge Telemetry:** Circom Groth16 ZK-SNARK circuit proving temperature compliance in **0.367 ms** without revealing sensitive transit routes (compressed 128-byte proof).
- **Physical Packaging Serialization:** GS1 Digital Link Standard v1.2 resolution paired with dynamic challenge-response NFC (NTAG 424 DNA SUN protocol).
- **Target Publication:** Manuscript submitted to the *IEEE International Conference on Blockchain and Cryptocurrency (ICBC)*.

`Solidity 0.8.26` · `NestJS` · `Next.js 14` · `PostgreSQL` · `Hardhat` · `Circom` · `Docker` · `TypeScript`

[Repository](https://github.com/MirEashanZaman/pharma-trace) · [Architecture Video Walkthrough](https://youtu.be/_FZelSTRM6g?si=TDKKbgOwiqq4Dijc)

#### 2. Student Tuition Payment Agent // FinTechathon 2026 International Track
*Autonomous cross-border remittance agent engineered with strict deterministic safety guardrails.*

- **Deterministic Safety Pipeline:** 3-tier permission matrix (`READ_ONLY`, `DRAFT`, `EXECUTE`) preventing unauthorized autonomous balance mutations.
- **Saga Orchestrator:** Multi-step transactional transfers with automated compensating rollbacks to eliminate balance desynchronization.
- **Cryptographic Security:** `scrypt` key derivation, SHA-256 transaction fingerprints, step-up 2FA OTP, and tamper-evident A4 payment certificates.
- **Rigorously Tested:** 80 automated unit and integration tests executing on continuous GitHub Actions CI.

`NestJS` · `Next.js 14` · `Gemini AI Agent` · `PostgreSQL` · `Docker` · `Zod` · `TypeScript`
