## 🌟 Featured Project

### 🛢️ [Oil Supply & Delivery Management System](https://github.com/MirEashanZaman/oil-supply-and-delivery-management-system-frontend)
> *A unified Web and Native Mobile logistics ecosystem for managing downstream petroleum distribution, live delivery tracking, and multi-tier energy trading.*

- **5 Dedicated Personas**: Role-tailored dashboards for **Admins**, **Refinery Suppliers**, **Station Dealers**, **Industrial Customers**, and **Delivery Drivers**.
- **Mobile Ready**: Packaged native Android & iOS app via Capacitor with offline session caching.
- **Enterprise Engineering**: Built with NestJS, TypeORM, Next.js 16 (App Router), PostgreSQL, and Pusher real-time WebSockets.
- **Security**: Strict Token-Bucket Rate Limiting (anti-brute-force), JWT authentication, and tamper-evident audit logging.
